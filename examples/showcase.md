# Markdown, with room to breathe

A terminal should be able to show a **real heading**. `ma` brings familiar GitHub typography into Ghostty and Kitty, with proportional text and a clear visual hierarchy.

## A familiar reading experience

At the default size, this is a second-level heading at **36 px**, below a title at **48 px**. Body text is **24 px**. These are actual font sizes, drawn by our native renderer and displayed through Kitty graphics.

### Details that matter

- **Emphasis**, *italics*, and ~~strikethrough~~.
- Inline `code` with a subtle background.
- [Links that look like links](https://github.com).
- Nested lists with comfortable spacing:
  - Typography scales with the terminal.
  - Long paragraphs wrap naturally.

> Good typography makes the structure of a document visible before you read a word.
>
> Blockquotes get a quiet border and muted text.
