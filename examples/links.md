# Link navigation

Click a link, or press **Tab** to select one and **Enter** to open it.

- [Read the README](../README.md)
- [Jump to the README controls](../README.md#controls)
- [Explore the Markdown showcase](showcase.md)
- [Jump to details below](#details)
- [Open the project on GitHub](https://github.com/liuyang1520/ma)

Use **h** and **l**, or **Alt-Left** and **Alt-Right**, to go back and forward.

## Details

Local Markdown opens inside `ma`. Web links open your default browser.

Link labels can contain [**bold text**, *italics*, and `inline code`](../README.md#rendering-and-scrolling), and remain clickable when they wrap across lines.
